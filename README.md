## О проекте

Одностраничный адаптивный лендинг для вымышленного VPN-сервиса **Astra VPN**: hero-секция с превью дашборда, блок фич, витрина серверов, отзывы на бегущей ленте, тарифы и FAQ. Тёмная тема, тёплый оранжевый акцент, плавные scroll-анимации.

## Стек

- **HTML5** — семантичная вёрстка
- **CSS3** — кастомные свойства, `clamp()`-адаптив, keyframe-анимации
- **Vanilla JS** — `IntersectionObserver` для scroll-reveal, чистого меню на `checkbox`

Без сборщиков и зависимостей — просто открой `index.html`.

## Возможности

- 🎬 Плавные появления секций при скролле
- 📱 Полный адаптив: десктоп → планшет → мобильный
- 🌗 Тёмная тема с акцентным свечением
- 🖱 Микро-интеракции на кнопках, карточках и иконках
- 🎠 Бесконечная лента отзывов (marquee)
